# Смоук-тест платежа

Тесты создают настоящие платежи в запущенном приложении. Первый проверяет создание и получение платежа, второй дополнительно ожидает итоговый статус. Для обработки нужны PostgreSQL и Kafka. Результат симуляции может быть как `success`, так и `failure`.

Из корня проекта запусти сервисы:

```bash
DB_USER=postgres DB_PASSWORD=password DB_HOST=db DB_PORT=5432 DB_NAME=backend docker compose up -d --build smart-path
```

После запуска приложения выполни:

```bash
go test -tags=smoke -count=1 -v ./tests/smoke
```

Для отдельной проверки создания и чтения платежа:

```bash
go test -tags=smoke -count=1 -v ./tests/smoke -run '^TestPaymentCreation$'
```

При проверке 2 ноября 2026 года тест обработки не прошёл: платёж остался в `pending` в течение 30 секунд. Это нужно исследовать в приложении.

По умолчанию используется `http://localhost:8080`. Другой адрес можно передать через `SMOKE_BASE_URL`. Каждый запуск создаёт новую запись в базе. Тесты запускаются отдельно от обычного `go test ./...`. В CI подключён только `TestPaymentCreation`; проверку обработки нужно подключить после устранения проблемы со статусом `pending`.
